# Memory利用状況の記録

ユーザーはMemoryとrecallがどれだけ活用されているかを確認したいと依頼し、最低限Memoryの利用ログを求めた。現行のlog.mdは作成・更新・関連付け・削除の履歴であり、検索・参照の集計ではない。sources.usage_countも入力属性で、自動計測値ではない。

追加質問への回答で「検索・参照した回数と、対象の知識を記録・集計する」を選択した。実際の判断への採用と理由の記録は今回の範囲に含めない。

## 初期範囲

Memory CLIのsearch/showに`--record-usage`を追加し、成功した検索・本文取得と同じ呼び出しで利用イベントを保存する。既存の指定なしの呼び出し、公開された読み取りAPI、usage list/statsは読み取り専用を維持する。Memoryスキルは通常の開発で記録オプションを使い、明示された書き込み禁止・読み取り専用では省く。Tasks未登録の調査でも利用ログのためにタスクを作らない。

イベントには日時、選択project、操作、結果に含まれたconcept ID、show対象の内容ハッシュ、actor、呼び出し元、任意のtask_idを保存する。actorと呼び出し元は自己申告であり認証情報ではない。検索文、絞り込みの値、知識本文は複製しない。検索の結果一覧に出た回数と、showで本文を取得した回数を区別し、実際の判断への採用・有用性とは扱わない。

呼び出し元には`--usage-source`でdevlow・recall等を付けられる。ただしrecall経由のMemory呼び出し数は、recall自体の起動回数ではない。recall全体の実行計測や判断への採用理由は今回の初期実装に含めない。

## 保存と照会

保存先は`.space/<project>/memory/usage/events/<UUID>.json`。イベントは1件1ファイルとし、既存の安全なファイル操作・排他・書き込み予定・復旧を使う。外部依存、他CLIとの共有実装、サービス送信、知識本文のアクセス回数更新を追加しない。通常の知識検索・検証からは利用ログを除外する。

`usage list`は新しい順の記録を返し、`usage stats`は検索数、本文取得数、結果ゼロの検索数、知識別の結果出現回数・本文取得回数を返す。期間、actor、呼び出し元、task_idで絞る。ログがない場合は空の記録とゼロ件を返す。未初期化のMemoryをログ取得のために初期化しない。

記録を明示した呼び出しでログ保存に失敗した場合は成功とせず、既存の書き込み失敗・復旧手順に従う。検索・参照に失敗した場合は成功イベントを残さない。各呼び出しを数えるため同じ検索の繰り返しも別イベントとする。読み取りAPIやMarkdownの直接参照、記録指定のない呼び出しは集計対象外。

イベントはCLI内部の取得処理の成功を表す。ログ保存後に応答が失われた場合や、ログ保存の中断からrecoverで元のイベントを完成させた場合も残るため、呼び出し元が結果を受領・読解したことを保証しない。並行する書き込みは既存の排他に従い、ロック競合を成功と扱わない。

## 実装と検証

所有する変更はMemoryの利用記録モジュール、CLI入口・JSON入力、Memoryと連携スキルの利用手順、設計資料、配布物、対応するテストとする。CLIの既存応答dataとraw出力は保持し、記録指定時のJSON応答だけ利用イベントの参照を付ける。

成功時の記録と集計、ゼロ件、日時・実行者・呼出元・タスクの絞り込み、知識削除後の記録保持、読み取り専用での無変更、プロジェクト分離、壊れたログ・シンボリックリンク・ロックの拒否、書き込み途中失敗の復旧を確認する。両製品の配布CLI単独実行、全テスト、型検査、生成物照合、GitHub CIを確認し、developへ履歴を残して統合する。

## ローカル検証

2026-11-01、Bun 1.4.4で利用記録の10テスト・84 assertionsが成功した。記録付きCLIの実行を使い、通常の記録・絞り込み・集計、記録なしの無変更、対象削除後の保持、破損・領域外アクセス・ロックの拒否、権限エラーからの復旧、並行呼び出しで成功したイベントの保持を確認した。実装前の追加テストは未対応コマンド・入力フィールドで失敗していた。

全285テスト・2022 assertions、型検査、194ファイルの配布物照合が成功した。配布物のテストではソースと他のCLIを取り除き、Codex・Claude CodeそれぞれのMemory単独で記録・一覧・集計・知識削除後のログ保持を確認した。Memory・devlow・recallのスキル形式検証も成功した。

スキルの記録方針は文書の確認であり、実際のCodex・Claude Codeセッションが指示どおり毎回記録することを計測した結果ではない。Macの既存プラグインへのインストール更新、NPM公開、版数変更は行っていない。GitHub CIとdevelopへの統合結果は対応するPRで確認する。
