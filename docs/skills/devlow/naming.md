# 統括スキルの名称

## devlawへの変更（2026-11-14）

ユーザーの指定により、開発の統括スキルをdevlawへ変更した。lawは開発の原則・進め方・完了条件を定める役割を表す。現行の入口は[devlaw](../../../skills/devlaw/SKILL.md)であり、担当名もdevlaw-workerとする。旧名の互換入口や案内用スキルは設けない。

スキルのディレクトリとfrontmatter、利用側の参照、両製品のエージェント定義、三製品の指示テンプレート、README、Memoryの呼び出し元名の例、配布検証を更新した。工程・CLIの動作・保存形式は変えない。運用用スキルの追加は今回の対象外。

過去の開発資料と評価記録は当時の名称・ハッシュを保持し、現行ソースへのリンクを更新する。利用先に保存済みのタスク・利用ログや、既に導入された旧スキル・担当ファイルは書き換えない。setupの既存方針に従い、新しい配布物から消えたファイルの自動削除も追加しない。

検証はBun 1.4.2で実施した。325テスト・2442 assertions、型検査、配布物の生成結果との一致確認が成功。配布対象の本文・パスにdevlowが残っていないこと、両形式とも18スキルであること、改名先を指す開発資料の58リンクが存在することも確認した。実行結果はスキルの実行品質を再評価したものではない。

## devlowへの名称統一（2026-09-23）

2026-09-23。ユーザーの指定により、統括スキルの名称をdevlowへ統一した。旧名への互換入口は設けない。

既存の作業台帳は文字列を統一し、過去の検証ハッシュは当時の値を保持した。以前の配布作業の親unitについてdoctorが対象変更を検出することを確認した。過去の合格を改名後の確認として扱わず、今回の結果は以下に分けて記録する。

- 旧版でsetup済みの一時プロジェクトを両製品の新版へ更新。指示がdevlowを参照し、管理ブロック外の既存指示を保持すること、再適用で変化しないことを確認。
