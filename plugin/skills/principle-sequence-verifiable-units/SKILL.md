# Sequence Work into Verifiable Units

作業を、それぞれ確かめられる状態で終わる小さな単位に並べ、今の単位が通るまで次へ進まない。

一括修正、移行、同種の編集の繰り返しでは、各単位を「正しいと分かっている状態、一つの変更、確認の実行、次へ」という一組にする。道具が編集する場合も、単位ごとの確認を実行する。

作業が正しいことを示す順で届ける。失敗するテストを先に、修正を後に。作り直しの前に引き算を。処置の前に基準の測定を。各コミットは単独で成り立つようにする。
