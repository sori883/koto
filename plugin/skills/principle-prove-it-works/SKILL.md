# Prove It Works

すべての成果は、実物を直接確かめて検証する。機能を動かし、実際の値を読み、差分を見る。代わりの指標（ファイルの更新時刻、自己申告、キャッシュされた出力、「コンパイルできた」）は数えない。確認が失敗したら、システムより先に観察の方法を疑う。

できるなら確認をスクリプトにする。比較を再実行できる、決まった結果を出すスクリプトは、一度きりの目視に勝る。出力は人が見られる場所に残し、後から監査できる記録が必要な場合だけコミットする。
