# Minimize Reader Load

読む負担とは、コードを理解するために読む人がしなければならない作業である。互いに独立した2つの軸がある。問いから答えまでにたどる層の数と、頭に抱えておく隠れた状態・変更可能な状態である。両方を抑える。

- 受け渡すだけの層を畳む。呼び出し元が一つのラッパー、二つ目の実装がないアダプター、素通しのメソッドは、呼び出し側に展開する。
- 状態の範囲を狭める。変更より戻り値、フィールドよりローカル変数、モジュールの状態よりフィールド、グローバルよりモジュールの状態を選ぶ。同期させるのではなく、導き出す。
- 不変条件は、すべての利用側ではなく、境界で一度だけ名前を付ける。

確かめ方：初めて読む人が「Xはどこから来るか」「Xを変えられるのは何か」に30秒以内で答えられるか。答えられなければ、層か状態を減らす。
