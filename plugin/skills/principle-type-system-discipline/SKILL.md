# Type System Discipline

ありえない状態、取り違えたプリミティブ、処理していない種類を、コンパイラが拒否するようにする。

- **意味のあるプリミティブに型を付ける。** 同じプリミティブ型でも意味の違う2つの引数には、それぞれ別の型を付ける。検証は作るときに一度だけ行う。
- **外部データは解析するまで型がない。** JSON、RPCの内容、CLIの引数、設定、環境変数、データベースの行は、境界で型付きのモデルを返す解析関数を通す。
- **すべての種類を処理する。** 判別共用体や列挙型の分岐は、処理していない種類があればコンパイルが失敗する形にする。
- **正本のスキーマから型を導く。** 形を持つスキーマファイルがあるなら、並行する型を手で書かず、スキーマから導く。
