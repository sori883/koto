# AIが生成したコードのslopを取り除く

mainとの差分を確認し、このブランチで持ち込まれたAI生成のslopを取り除く。

## 重点項目

- 不要なコメント、またはその場のスタイルと合わないコメント
- 信頼できるコードパスでは不自然な防御的チェックやtry/catchブロック
- 型の問題を回避するためだけの`any`へのキャスト
- 早期リターンで単純にできる深いネスト
- そのファイルや周囲のコードベースと合わないその他の書き方

## 守ること

- 明らかなバグの修正でない限り、動作を変えない。
- 広い書き直しより、最小限で的を絞った編集を優先する。
- 最後の要約は簡潔にする（1〜3文）。
