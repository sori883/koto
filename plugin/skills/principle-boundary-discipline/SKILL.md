# Boundary Discipline

データがシステムの境界（CLIの引数、設定ファイル、外部API、ネットワーク）を越える場所で、検証し、型を絞り、エラーを処理する。内側では型を信頼し、再検証や重複したnullチェックをしない。生のデータは境界でドメインの型に解析し、通信やフレームワークの型を公開する面に出さない。業務ロジックはフレームワークに依存しない純粋な関数に置き、それを呼ぶ外側は薄くする。

確かめ方は2つ。このデータは今、境界を越えているか。越えていなければ、その検証は重複である。これは外側から呼ぶだけの純粋な関数にできるか。できるなら、切り出す。
