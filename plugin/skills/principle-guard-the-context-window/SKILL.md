# Guard the Context Window

**理由：** コンテキストがあふれると、推論の質が落ち、圧縮による欠落が生まれ、作業が止まる。

**やり方：**

- **大量の作業は任せる。** 大きな出力、長いファイルの読み込み、広い検索はサブエージェントに任せ、主のスレッドには結論と要約だけを戻させる。
- **段階の大きさを決め、範囲に上限を付ける。** 段階ごとのファイル数を限り、やり取りの回数の予算を決め、仕組み自体にかかる量も見積もる。
