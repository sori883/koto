# How

コードベースを調べて、「Xはどう動くのか」という質問に答える。

範囲が曖昧なら、自分の解釈を述べて調べ始める。利用者は軌道修正できる。

## 1. 説明する

`Agent`ツールで、`subagent_type: "Explore"`（読み取り専用のサブエージェント）を一つ起動し、調べることと説明することを一度に任せる。利用者の質問と、次の依頼を渡す。

> あなたは、シニアエンジニアに向けて構成の説明を書く。コードベースを調べ、この領域を知らないシニアエンジニアが読めば、しっかりした全体像を持って帰れる説明を書くこと。読んだ人が、自信を持ってこの領域で作業を始められる程度に構成を理解できるようにする。コードベースへのアクセスは読み取りだけとする。

## 2. 示す

サブエージェントの出力を示す。分かりやすくするための軽い手直しや、会話の文脈を足すことはよい。大きく書き直さない。
