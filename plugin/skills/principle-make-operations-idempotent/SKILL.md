# Make Operations Idempotent

状態を変える操作はすべて、何度実行しても、前の実行がどこで止まっていても、正しい状態に収束するよう設計する。

各段階は、前の実行がしようとしたことではなく、今ある状態から導く。今の状態を読み、目標と比べ、差分だけを適用する。

実行が残すもの（ロック、一時ファイル、書きかけの記録、確保した仕事）は、前の実行がどこで止まっていても成り立つ証拠によって、次の実行が古いものと判別できるようにする。書き込みは一時的なパスに行い、名前を変えて所定の場所に置く。

確かめ方：これを2回実行したらどうなるか。前の実行があらゆる地点でクラッシュしていたらどうなるか。答えが残されたものに左右されるなら、照合の段階を足す。
