# Laziness Protocol

削除と、問題を解く最小の変更を優先する。

- **判断を一か所にまとめる。** 同じ選択を複数の場所で繰り返さない。一つの正本の後ろに置き、結果を単純なフラグとして渡す。
- **差分を最小にする。** 問題を解く最小の変更をする。「きれいな」定型コードより、行数の少なさを選ぶ。
