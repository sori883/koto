# Explain the Number

- **実行する前に判断を書く。** 判断を変える結果と、雑音の大きさを書いておく。実行ごとのばらつきが効果より大きければ、そこで止める。
- **「なぜ2倍にならないのか」を問う。** 結果を制限している資源やコードの経路を、実行中に取ったプロファイルやカウンタから特定する。コードを読んだだけの推測は、制限要因ではない。
- **その数値が測っているかもしれない別のものを挙げる**（エラー、飛ばされた・キャッシュされた作業、実行されなかったコード、調整されていない比較対象、雑音、影響が小さすぎる部分）。それぞれを証拠で除外する。
- **実行回数、ばらつき、制限要因を、数値と一緒に残す。**

評価結果では、すべての実行が課題をこなしたか、差が試行やモデルをまたいで保たれるか、その場面が重要かを問う。
