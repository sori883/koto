# Encode Lessons in Structure

同じ指示を2回書いたら、それは文章ではなく仕組みにすべき決まりである。lint、メタデータのフラグ、実行時の確認、スクリプトとして組み込む。

学びに判断が必要で仕組みにできない場合は、その指示を目立つ場所に置き、失敗の例を添える。

**補足：** 仕組みで直せるなら、仕組みの修正だけを使う。指示文は症状にすぎない。
