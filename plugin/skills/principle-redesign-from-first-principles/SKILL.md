# Redesign From First Principles

変更を組み込むとき、既存の設計に後付けしない。その要件が最初からの前提だったかのように設計し直す。

- 影響するファイルをすべて読み、今の設計を理解する。
- 「この要件を前提に最初から書くなら、何を作るか」を問う。
- 変更を、型、文書、例、理由の説明まで、すべての参照先に行き渡らせる。
- 設計し直す全体を考えてから、少しずつ届ける。

これは、変更を組み込みながら将来の選択肢を残すための方法である。
