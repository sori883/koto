# Attack the Premise

同じ前提に立つ修正が2つ以上、同じ確認で失敗したら、修正ではなく前提を疑う。

- 前提を書き出す。失敗した修正がすべて仮定していた一文にする。
- 次の修正の前に、前提を確かめる。前提が間違っていれば結果が変わる観察を見つけ、実際に行う。失敗の大きさだけでなく、失敗の分布を見る。
- 証拠が前提と食い違ったら、前提が予測しなかった、失敗に共通するものを探す。ある部分がいつも負ける側に来るなら、後始末の仕組みを足すのではなく、それをそこへ置いているものを変える。

前提を書き出して確かめるまで、次の修正を始めない。
