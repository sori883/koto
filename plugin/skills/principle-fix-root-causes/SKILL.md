# Fix Root Causes

症状が表に出た場所ではなく、誤りそのものを直す。根本原因とは、システムがすべきでないことを最初にした場所、または扱うべき状態を最初に扱えなかった場所である。

- まず再現する。答えがコードの誤った判断になるまで「なぜ」を繰り返す。行き詰まったら、計測を入れて実際の状態を読む。
- 症状を起こした状態が正当かどうかを問う。正当なら、コードが壊れた場所で扱う。決して存在すべきでない状態なら、そこでの確認は不具合を隠すだけなので、何がその状態を作ったかを探す。ガード、再試行、握りつぶしたエラー、丸めた値、捨てた状態が、不具合を隠すよくある方法である。
- 一件ではなく、型を直す。同じ誤りがあるすべての場所を探す。
- 決め手の事実を見つけるのに深く掘る必要があったなら、最初の一目でそれが分かったはずの、安くて常に有効な手がかりを提案する。
